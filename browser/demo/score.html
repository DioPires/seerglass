Score a video in this browser

Finds each labeled frame of your manifests in your video files and records what would be shown at each labeled position, as a file for the command-line scorer. Nothing leaves this computer. Keep this page visible: a run pauses while it is hidden.

Demo page

  1. The address of a release document. It is filled in when the server was started with a release folder.

  2. One or more label manifests, the .manifest.jsonl files.

  3. A video is found by its file name: the video id, or the platform, a hyphen and the video id. A file that holds a section of a video adds a plus sign and its start in seconds. Example: local-table+2.webm holds the video table of the platform local, from 2 seconds in.

Options

Optional: the video-files.json beside kept video files.
